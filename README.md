# Beverage Sales & HR Analytics Project (Power BI)

## Overview

This project presents two interactive **Power BI reports**:
- **Beverage Sales Analytics** (1-page report)  
- **HR Analytics** (2-page report)  

It demonstrates data modeling, DAX calculations, and dashboard design to generate actionable business insights.

---

### Dataset
Includes:
- Retailer, Retailer ID  
- Date, Month  
- Division, District  
- Beverage Brand  
- Price per Unit, Units Sold, Cost per Unit  
- Additional tables: Dates, Cost

Also includes employee data such as:
- Employee ID, Age, Gender  
- Department, Job Role  
- Salary, Performance Rating  
- Work-Life Balance, Job Satisfaction  
- Hire/Exit Dates and Employment Details

- <a href="https://github.com/NafizNewaz/Sales_-_HR_Analytics_Power_BI/blob/main/Dataset.xlsx">Dataset</a> 

## 1. Beverage Sales Analytics

### Data Preparation
- Created relationships between tables  
- Cleaned data using Power Query  
- Created measures and columns using DAX:
  - Total Revenue  
  - Total Cost  
  - Profit  
  - Average Price per Unit  

### Report
- Visuals for sales performance and trends  
- Interactive filtering and insights by region, brand, and time
- <a href="https://github.com/NafizNewaz/Sales_-_HR_Analytics_Power_BI/blob/main/Sales%20Performance%20Task.pbix">Dashboard</a> view

## 2. HR Analytics 

### Data Modeling
Created DAX measures:
- Total Employees  
- Current Employees  
- Terminated Employees  
- Salary Paid  
- Termination Rate  

### Report Structure

#### Page 1: HR Overview
- KPIs: Total Employees, Current Employees, Terminated Employees, Termination Rate  
- Clustered Column Chart: New Hires vs Terminations (Quarterly)  
- Area Line Chart: Terminations by Month  
- Pie Chart: Employees by Environment Satisfaction  
- Combo Chart: Salary by Working Years & Gender  

#### Page 2: HR Analysis
- KPIs: Current Employees by Gender, Salary Paid  
- Funnel Chart: Employees by Education  
- Area Line Chart: Salary by Month  
- Pie Chart: Work-Life Balance Distribution  
- Clustered Column Chart: Salary by Working Years & Employment Type  
- Navigation buttons used to switch between pages

- <a href="https://github.com/NafizNewaz/Sales_-_HR_Analytics_Power_BI/blob/main/HR%20Analytics%20Task.pbix">Dashboard</a> view
